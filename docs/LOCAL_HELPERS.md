# Local media helpers

Trusted bundled helper resources work from canonical cache directories and macOS temporary-directory aliases. Only the Bundle resource's parent is resolved with POSIX realpath. Managed current/prior helpers still require no-follow ancestor/leaf traversal, a single regular-file link, bounded reads and matching content hashes. Symlinks, hard links, FIFOs and changed managed bytes remain rejected; existing helpers and settings are preserved on failure.

The application is native Swift/SwiftUI. Installed FFmpeg/FFprobe, yt-dlp and rclone are local executables, not services. The bundled ASR adapter is reused from Frank's existing DUB skill package (`runtime/x/scripts/transcribe_source.py`, version 1.3.5); original SHA-256: f41ff480247f1be47366b4a883964eb2f3e17ed085aa4b866cd6f13dc1d0722b. It invokes the existing local MLX Whisper/faster-whisper model with Hugging Face offline mode. No model, credentials or production media are included in Git.

The approved DUB artwork is resolved from its exact Drive ID or a hash-verified existing asset, then copied into application-owned storage. The app does not need the Codex process, ChatGPT, GitHub or Xcode Cloud to run. Existing local Python/model paths are operational dependencies configurable in settings.

The development target runs outside App Sandbox because its authorized workflow invokes existing user-installed tools and accesses existing archive/media paths and the existing rclone configuration. It retains macOS permissions and user authorization checks; it does not grant new cloud access. This local build is not a public distribution/notarization claim.

Implicit helper stdout and stderr use anonymous memory capture. Each stream has the configured live byte budget, defaulting to 16 MiB, while stderr retains its final 6000 diagnostic bytes. OAuth configuration capture has a 1 MiB budget and suppresses configuration/parser error content. Explicit media stdout file outputs retain their existing behavior. Overflow detection can consume one additional 16 KiB read chunk. Once detected, capture stops draining and the existing supervisor terminates the process group, leaving only finite kernel-pipe buffering under backpressure. Dummy-only macOS probes measured 81,920 completed producer bytes at a 1024-byte capture limit, with at most one additional 4096-byte in-flight producer write and termination near 1.30 seconds. Those measurements describe this host, while retained memory remains within the configured limit. Final pipe drainage has a two-second post-exit deadline.

The native operation owns transient retries. yt-dlp's download, extractor and fragment retries are disabled under that owner. rclone network helpers explicitly use `--retries 1 --low-level-retries 1`. Read operations receive at most three native attempts, while uncertain external writes retain their existing reconciliation-before-retry loops. Controlled tests count failing endpoint requests separately from required manifest reads and mutation readbacks.

Acquisition validates canonical, supplied and raw transcripts against the complete source ID, SHA-256 and duration. A valid cached transcript does not require the helper/model to remain configured. For a qualifying final timestamp overrun in local ASR, the adapter extracts at most 30 seconds from a non-crossing segment boundary and invokes the same offline helper with a 180-second timeout. Only genuine regenerated word times are shifted into original source coordinates. The rejected raw ASR, excerpt and regenerated JSON are retained with hash-bound repair evidence; invalid output remains an actionable failure. Cancellation and storage shortages retain their original recovery signals. This is a timing/source-integrity repair, not a claim that ASR text is semantically error-free.
